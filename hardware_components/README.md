These hardware components were purchased on Aliexpress, but most of them are also available on Amazon.

For the mechanical platform, a parts list is provided in the [original project used for the mechanical design](https://howtomechatronics.com/projects/diy-mars-perseverance-rover-replica-with-arduino/). An [extended version of the mechanical parts list](/hardware_components/mechanical_parts_list.txt) is also provided in this ``hardware_components/`` folder, which includes the remote controller's parts.

### Cost
This is the estimated cost of all the mechanical and hardware components: 

-For the rover, around 900€

-For the first remote control option (custom RC PCB), around 120€

-For the second remote control option (attachment for a generic/commercial RC), around 40€ (not including the generic/commercial RC)

This cost does not include the tools that are necessary to build the rover and remote controller (e.g., soldering iron, power supply for tests, multimeter).
