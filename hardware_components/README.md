## Hardware components

![Alt text](/images/hardware_components.jpeg)

Here is a list with the most important hardware components needed for the rover:

- NEMA17 stepper motor (x1)
- Toggle switch 20A (x1)
- SS-12D10 switch (x2)
- Arduino Mega (x1)
- MG996R/DS3225 servo (x10)
- XD-37GB555 motor (x6)
- NRF24L01 transceiver module (x2)
- NRF24L01 3.3V regulator (x2)
- XT60 connector female and male (x1)
- DRV8871 motor driver (x6)
- SZBK07 buck converter 20A (x1)
- 22AWG wire 20 meters red and 20 meters black (x1)
- 14AWG wire 1 meter red and 1 meter black (x1)
- Servo extension cable 22AWG 5 meters (x1)
- Dupont jumper wires (as needed)
- BME280 sensor (x1)
- 12V 4010 fan (x2)
- Arduino Nano (x1)
- A4988 stepper motor driver (x1)
- Matte Black vinyl wrap (as needed)
- Self closing braided sleeve for cables (as needed)
- JST-XH male and female connectors (as needed)
- Micro limit switch with roller (x1)
- Jack 3.5mm mono connector (x1)
- 6000mAh 11.1V 50C LiPo battery (x1)
- XL4015 buck converter 5A (x2)
- Mini buck converter 2A (x1)
- 4-channel logic level converter (x1)
- ESP32S3_8048S043 IPS touchscreen (x1)
- RaspberryPi Zero 2W (x1)
- RaspberryPi Cam V3 Wide (x1)
- FFC cable 15 centimeters for PiZero and PiCam (x1)
- Heatsink for PiZero (x1)
- CP2102 USB to TTL converter (x1)
- 4-USB HAT for PiZero (x1)
- 1N5817 Schottky diode (x3)
- Prototyping boards (as needed)
- Buzzer (x2)

These hardware components were purchased on Aliexpress, but most of them are also available on Amazon.

For the mechanical platform, a parts list is provided in the [original project used for the mechanical design](https://howtomechatronics.com/projects/diy-mars-perseverance-rover-replica-with-arduino/). An [updated version of the mechanical parts list](/hardware_components/mechanical_parts_list.txt) is also provided in this ``hardware_components/`` folder.

### Cost
The estimated cost of all the mechanical and hardware components is around 900€. This cost does not include the tools that are necessary to build the rover (e.g., soldering iron, power supply for tests).
